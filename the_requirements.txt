
1. User Authentication:

Sign Up: Register users via Gmail.

2. Event Management:

Create: Add a new event (event name, date, location ...).

Retrieve a list of all events.

Delete: Remove an event (accessible only to admins or organizers).

3. User Profiles:

Get and update user information ( name, email, registration date).
